# NovaCare — الموقع ونظام إدارة العيادة

## التشغيل على ويندوز
1. فك ضغط المجلد بالكامل في مكان ثابت تقدر تكتب فيه.
2. افتح START-NOVACARE.cmd. يحتاج Node.js 24 أو أحدث. لا يحتاج npm install.
3. أول مرة: اكتب كلمة سر للإدارة من 12 إلى 256 حرفًا. الحروف بتظهر في نافذة الإعداد، فاعمل الخطوة بعيدًا عن الآخرين.
4. بعد ظهور NovaCare is ready، افتح:
   - الموقع: http://127.0.0.1:3000
   - لوحة الإدارة: http://127.0.0.1:3000/admin
5. اسم المستخدم الأول admin، وكلمة السر هي التي حددتها. سيب نافذة التشغيل مفتوحة.
6. من Clinic settings حدّث اسم العيادة والعنوان والتليفون والبريد. من Doctors حدّث أسماء الدكاترة والتخصصات؛ الأسماء والصور المرفقة توضيحية.
7. أضف حسابات الموظفين من Staff & access؛ لا تشارك حساب المدير.

لفتح شكل الموقع فقط بدون تشغيل النظام افتح NovaCare-Preview.html. الصور والتنسيق مضمّنان فيه. الحجز لا يُرسل من ملف المعاينة.

## الموجود في النسخة
- تصميم الموقع والترويسة الكحلي، وصور محلية، وبحث عن الخدمات.
- طلب حجز من الموقع حسب الدكتور والميعاد المتاح، مع رقم مرجعي.
- لوحة متابعة، حجوزات، تأكيد وحضور وإلغاء وتغيير موعد.
- بيانات المرضى الأساسية وسجل زياراتهم وملخص مستحقاتهم.
- إضافة وتعديل الدكاترة وإيقاف استقبال الحجوزات الجديدة.
- إصدار فاتورة داخلية، تسجيل دفع جزئي أو كامل، وطباعة.
- حسابات مدير واستقبال، تغيير كلمة السر، وسجل تغييرات.
- إنشاء نسخة احتياطية محلية من الإعدادات.

## قواعد التشغيل الحالية
- عيادة واحدة؛ المواعيد بتوقيت القاهرة، من الاثنين للسبت 09:00–20:00 بفواصل 30 دقيقة، والأحد مغلق.
- طلب الموقع يظل pending حتى تأكيده من الاستقبال. إلغاء الموعد يحرّر وقته.
- جميع المبالغ بالجنيه المصري. تسجيل Card يعني توثيق مبلغ تم تحصيله بالفعل؛ لا يسحب فلوس من بطاقة.
- المرضى والأطباء والزيارات لها معرفات مستقرة. لا يوجد حذف نهائي للسجلات من الواجهة.
- مبلغ الفاتورة لا يتغيّر بعد إصدارها. هذه فواتير داخلية وليست ربطًا بفواتير ضريبية إلكترونية.
- هذه النسخة تسجل بيانات التواصل والمواعيد والفواتير؛ لا تشمل سجلًا طبيًا إكلينيكيًا أو وصفات أو مخزونًا أو تأمينًا.
- واجهة النظام بالإنجليزية مثل المشروع الأصلي.

## البيانات والنسخ الاحتياطي
البيانات الحقيقية تحفظ في data/clinic.sqlite على جهازك، ولا توجد بيانات مرضى أو كلمات سر تجريبية داخل النسخة النهائية.
قاعدة البيانات والنسخ الاحتياطية ليست مشفّرة من التطبيق؛ احمِ حساب ويندوز والقرص ومجلد المشروع، ولا تشارك مجلد data.
زر Create backup يحفظ نسخة متسقة داخل data/backups. انسخها لمكان آمن آخر.
للاستعادة: أوقف الخادم، احتفظ بالمجلد الحالي كنسخة كاملة، ثم ضع نسخة SQLite المختارة في مجلد data جديد باسم clinic.sqlite. لا تخلط معها ملفات WAL/SHM القديمة. أعد التشغيل وسجّل الدخول بحساب موجود في النسخة المستعادة.
جلسات الدخول لا تستمر بعد إعادة تشغيل الخادم؛ البيانات تستمر.

## التشغيل عبر الإنترنت
هذه نسخة محلية فعلية، مربوطة على 127.0.0.1 فقط؛ المرضى من خارج الجهاز لن يقدروا يدخلوا عليها الآن.
للنشر العام يلزم استضافة وHTTPS، إعداد نطاق، سياسة بيانات مناسبة، نسخ احتياطي خارج الجهاز ومراجعة تشغيل وصلاحيات. لم يتم نشر الموقع أو ربط واتساب أو رسائل أو بوابة دفع.
لا تغيّر عنوان الربط وحده لتعرض النظام على الإنترنت.

## ملفات المطور
server.mjs: الخادم وقاعدة البيانات.
admin.html / admin.css / admin.js: لوحة الإدارة.
index.html / styles.css / script.js / images: الموقع العام.
tests: اختبارات API والصلاحيات والحجز والفواتير واستمرار البيانات.
شغّل الاختبارات بالأمر: npm test
شغّل النظام بالأمر: npm start
