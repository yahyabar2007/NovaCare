NovaCare clinic management
Read README-AR.md for Arabic setup instructions.
Windows: extract everything, then run START-NOVACARE.cmd.
Requires Node.js 24+. No npm install needed.
Website: http://127.0.0.1:3000
Staff: http://127.0.0.1:3000/admin
First run asks you to set the admin password. Username: admin.
Keep the server window open. This package is local-only, not publicly deployed.
Preview: NovaCare-Preview.html (standalone, no booking transmission).
